# 🏆 VBSJA - जिलावार प्रविष्टि एवं रैंकिंग डैशबोर्ड (Streamlit Application)

यह एप्लिकेशन **Google Spreadsheet** डेटा को लोड करके विभिन्न जिलों, ब्लॉकों और इवेंट श्रेणियों के आधार पर कुल प्रविष्टियों, प्रतिभागियों, फोटो और वीडियो का विश्लेषण एवं **रैंकिंग (Ranking)** प्रदान करता है।

---

## 📌 मुख्य विशेषताएं (Key Features)

1. **🏆 जिला रैंकिंग तालिका (District Ranking Table - Merged Value + Original Rank):**
   - **मर्ज प्रारूप (डिफ़ॉल्ट दृश्य):** संख्या और मूल राज्य रैंक को एकल कॉलम में बिना किसी अतिरिक्त शब्द ("Rank:") के दर्शाया गया है:
     - `District` (जिला)
     - `कुल की गई प्रविष्टि` — जैसे `10,844 (1)`
     - `कुल प्रतिभागियों की संख्या` — जैसे `1,185,144 (3)`
     - `कुल photo` — जैसे `500 (1)`
     - `कुल video` — जैसे `50 (1)`
   - **मूल राज्य रैंक की स्थिरता (Persistent Original State Rank):** यदि आप इवेंट केटेगरी से डेटा फ़िल्टर भी करते हैं, तब भी जिले के साथ उसकी **मूल राज्य रैंकिंग (Overall State Rank)** ही दिखेगी, न कि फ़िल्टर किए गए सब-डेटा की रैंक।
   - **दृश्य टॉगल (View Toggle):** यूजर "मर्ज प्रारूप (Value + Rank)" और "अलग-अलग कॉलम (Separate Columns)" के बीच स्विच कर सकते हैं।
   - **📌 शीर्ष फ़िल्टर सूचना (Active Filter Info Bar):** तालिका के ठीक ऊपर लागू किए गए फ़िल्टर का विवरण दिखता है।
   - **📄 PDF & 🖨️ Print Export:** A4 PDF रिपोर्ट और सीधे प्रिंट करने की सुविधा।

2. **🎯 जिला स्पॉटलाइट व रैंक चेकर (District Spotlight):**
   - ड्रॉपडाउन से जिला चुनें और उस जिले की चारों मूल राज्य रैंक (प्रविष्टि, प्रतिभागी, फोटो, वीडियो) एक साथ देखें। सलूम्बर (Salumber) के 500 Photos और 50 Videos #1 रैंक के साथ स्वतः उपलब्ध हैं।

3. **📋 सभी कॉलम का विस्तृत डेटा (All Columns Detailed Data):**
   - स्प्रेडशीट के सभी 12 कॉलम प्रदर्शित करता है (सलूम्बर गींगला माकड़सीमा के कॉलम K व L सहित)।

4. **🎛️ अत्यंत सरल फ़िल्टर (Minimal Clean Filters):**
   - **इवेंट केटेगरी (Event Category):** श्रेणी अनुसार चयन
   *(नोट: जिला, ब्लॉक, इवेंट स्तर, भागीदारी स्थिति एवं न्यूनतम प्रविष्टि फ़िल्टरों को यूजर निर्देशानुसार पूर्णतः हटा दिया गया है)*

5. **📈 विज़ुअल चार्ट्स (Visual Analytics):**
   - शीर्ष 15 जिलों का बार चार्ट
   - इवेंट स्तर के अनुसार प्रविष्टियों का पाई चार्ट (Donut Chart)
   - इवेंट केटेगरी अनुसार बार चार्ट
   - प्रविष्टि बनाम प्रतिभागी स्कैटर प्लॉट

6. **🔄 लाइव डेटा सिंक (Live Google Sheets Sync):**
   - Google Sheet से सीधे नवीनतम डेटा लोड करता है।
   - साइडबार में दिए गए **"🔄 डेटा रीफ़्रेश करें"** बटन पर क्लिक करते ही नया डेटा फेच हो जाता है।
   - इंटरनेट धीमा होने पर स्थानीय कैश (`vbsja_data.csv`) से तुरंत लोड होता है।

## 🚀 एप्लिकेशन चलाने का तरीका (How to Run)

### तरीका 1: एक क्लिक में चलाएं (One-Click)
फ़ोल्डर में स्थित **`run_app.bat`** फ़ाइल पर डबल-क्लिक करें।

### तरीका 2: टर्मिनल या PowerShell से चलाएं
```powershell
streamlit run app.py
```
या
```powershell
python -m streamlit run app.py
```

ब्राउज़र में यह स्वचालित रूप से `http://localhost:8501` पर खुल जाएगा।
